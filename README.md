# Hashieban / حاشیه‌بان

حاشیه‌بان یک افزونه تحلیل مالی و گزارش‌های مدیریتی برای فروشگاه‌های ووکامرس است که به فروشنده کمک می‌کند فروش، هزینه، سود، محصولات، مشتریان، سفارش‌ها، موجودی و پراکندگی جغرافیایی فروش را ساده‌تر تحلیل کند.

## Project status

**Stable — 1.0.0**

نسخه 1.0.0 برای انتشار عمومی آماده شده و تمرکز آن روی صحت محاسبات مالی، رابط فارسی روشن، ناوبری ساده و بسته نصب استاندارد است.

## قابلیت‌های اصلی فعلی

- محاسبه فروش، هزینه خرید کالا و سود
- هزینه‌های مستقیم سفارش و هزینه‌های عمومی فروشگاه
- تحلیل محصول، مشتری، سفارش و زمان
- تحلیل کانال‌های فروش برای ترب، ایمالز، گوگل، شبکه‌های اجتماعی، UTM و ورود مستقیم
- تحلیل تخفیف و کوپن برای سنجش فروش، سود، فشار تخفیف و سفارش‌های زیان‌ده
- مرجوعی و بازگشت وجه
- هشدارهای مدیریتی و سلامت داده
- نقشه فروش ایران و تحلیل استان/شهر
- شاخص‌های مدیریتی کسب‌وکار
- تحلیل موجودی و پیشنهاد خرید مجدد
- قفل سود تاریخی سفارش‌ها
- شاخص سریع گزارش‌ها برای فروشگاه‌های بزرگ
- ابزارهای گروهی، خروجی CSV و ورود هزینه خرید
- تجربه کاربری فارسی، دسترسی‌های تفکیک‌شده و زیرساخت فعال‌سازی قابل تنظیم

## اصول توسعه

- صحت مالی قبل از ظاهر
- حفظ تاریخچه مالی سفارش‌های قدیمی
- سازگاری با HPOS و APIهای رسمی WooCommerce
- رابط فارسی و قابل‌فهم برای کاربر غیرمتخصص
- وابستگی حداقلی و Assetهای محلی
- تست خودکار + تست دستی سناریوهای واقعی قبل از انتشار

## QA

```bash
composer qa
composer release:check
```

برای ساخت بسته تمیز انتشار بعد از تأیید تست‌ها:

```bash
composer release:build
```

قبل از هر انتشار جدید، QA خودکار و تست دستی سناریوهای واقعی اجرا شود.
