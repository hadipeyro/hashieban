حاشیه‌بان؛ هوش مالی، تحلیل سودآوری و گزارش‌های مدیریتی برای فروشگاه‌های ووکامرس.

== Description ==

حاشیه‌بان کمک می‌کند فروشنده بدون درگیر شدن با اصطلاحات پیچیده، بفهمد چقدر فروخته، چقدر هزینه کرده، چقدر سود داشته، کدام محصول یا مشتری بهتر بوده و چه کالاهایی نیاز به خرید مجدد دارند.

نسخه 0.99.1 یک Release Candidate برای تست قبل از انتشار عمومی 1.0.0 است.
