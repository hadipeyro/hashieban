# چک‌لیست تست نسخه 0.99.x حاشیه‌بان

این فایل برای تست دستی قبل از انتشار 1.0.0 است. هر مورد باید روی داده واقعی یا داده آزمایشی کنترل شود.

## 1. نصب و سازگاری
- فعال‌سازی افزونه بدون Fatal Error
- فعال بودن WooCommerce و HPOS
- تست PHP 7.4+ و وردپرس/ووکامرس هدف
- غیرفعال/فعال کردن افزونه بدون حذف اطلاعات مالی

## 2. فروش و سود
- سفارش با یک محصول
- سفارش چندمحصولی
- محصول با هزینه خرید صفر
- محصول بدون هزینه خرید
- هزینه مستقیم سفارش
- هزینه ثابت سفارش
- هزینه عمومی فروشگاه
- نمایش تومان/ریال بدون تغییر مبلغ واقعی WooCommerce

## 3. تاریخچه مالی
- قفل سود یک سفارش قدیمی
- تغییر هزینه ثابت بعد از Snapshot
- تغییر COGS محصول بعد از Snapshot
- اطمینان از ثابت ماندن سود تاریخی سفارش قدیمی

## 4. مرجوعی
- مرجوعی کامل
- مرجوعی جزئی
- مرجوعی چندباره
- حالت Restock و بدون Restock
- کنترل Tax/Fee برای جلوگیری از دوباره‌شماری

## 5. گزارش‌ها
- داشبورد 7/30/90 روز
- بازه سفارشی
- محصول، مشتری، سفارش و زمان
- نبض کسب‌وکار
- هوش هزینه
- نقشه ایران و Drill-down شهر
- هماهنگی مجموع گزارش‌ها با سفارش‌های مرجع

### هوش کانال‌های فروش
- سفارش با UTM ترب و ایمالز
- سفارش با UTM گوگل/اینستاگرام و ورود مستقیم
- سفارش قدیمی بدون داده منبع باید «بدون داده منبع» بماند و حدس زده نشود
- کنترل دستی فروش و سود یک کانال نمونه

### هوش تخفیف و کوپن
- سفارش دارای یک کوپن با سود مثبت
- سفارش دارای کوپن سنگین و سود منفی
- سفارش بدون کوپن برای مقایسه
- سفارش چندکوپنی و هشدار هم‌پوشانی ردیف‌ها
- ویرایش کوپن سفارش و اطمینان از بروزرسانی شاخص سریع
- کنترل دستی مبلغ تخفیف، سود باقی‌مانده و درصد سود

## 6. موجودی و خرید
- محصول دارای مدیریت موجودی
- محصول بدون مدیریت موجودی
- موجودی صفر و منفی
- محصول پرفروش کم‌سود
- محصول کم‌فروش با موجودی بالا
- منطقی بودن پیشنهاد تعداد خرید

## 7. فروشگاه قدیمی
- سفارش قدیمی بدون شهر/استان
- سفارش قدیمی بدون COGS
- Geo Backfill
- Profit Snapshot Backfill
- ساخت شاخص سریع گزارش‌ها
- هیچ داده قدیمی نباید به‌خاطر اجبار فیلدهای جدید Block شود

## 8. امنیت و دسترسی
- Administrator
- Shop Manager
- کاربر بدون دسترسی مالی
- Nonce عملیات حساس
- CSV Import/Export
- فایل CSV با سلول شروع‌شونده با = + - @

## 9. UX فارسی
- نبود اصطلاحات فنی نامفهوم در صفحات اصلی
- توضیح ساده برای «هزینه خرید کالا»، «درصد سود»، «مرجوعی» و...
- نمایش صحیح عدد منفی در RTL
- نبود Flash منوی مخفی هنگام Refresh
- لینک‌های مرکز تحلیل‌ها همگی باز شوند
- صفحه‌ای با خطای «اجازه دسترسی ندارید» نباشد

## 10. Performance
- فروشگاه کوچک بدون پیچیدگی اضافه
- تست با تعداد بالای سفارش
- تکمیل خودکار شاخص سریع
- Refresh چند صفحه گزارش پشت سر هم
- عدم Timeout در Batchهای گروهی

## قبل از 1.0.0
- `composer qa` باید PASS باشد.
- `composer release:check` باید PASS باشد.
- تمام باگ‌های Blocker/Critical بسته شده باشند.
- متن‌های فارسی یک دور کامل بازخوانی شوند.
- ZIP نهایی فقط با `composer release:build` ساخته شود.
